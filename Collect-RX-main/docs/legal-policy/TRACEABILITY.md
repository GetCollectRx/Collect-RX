# Traceability matrix: obligation to policy, control and test

> DRAFT. Not reviewed by a lawyer. Positions per the founder's signed risk register. This matrix records what exists; it is not a compliance statement.

`Collect-RX-main/scripts/check-traceability.cjs` validates this table in CI and fails loudly when:
- a backticked path in the Policy document column does not exist;
- a row with status IMPLEMENTED names a control or test path that does not exist, or names no test path;
- a row with status PENDING_PR does not name a pull request (`#123`);
- the evidence tag, status or review date is not in the allowed form, or an ID repeats.

Statuses: IMPLEMENTED (control and test exist on this branch), PENDING_PR (control in an open PR), PLANNED (named in a plan, not started), NOT_BUILT (gap with no plan yet), POLICY_ONLY (enforced by process, no code). Tags: VERIFIED, EXCERPT, UNVERIFIED (a qualifier in parentheses may follow). Paths are relative to the repository root. Research rows live on PRs #119, #126, #127.
