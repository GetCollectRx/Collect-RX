# HIPAA gap review — template (P5-06)

Use with security/privacy and counsel. This is a **checklist template**, not evidence of compliance.

2. **Physical** — who can access prod laptops / offices with prod access.
3. **Technical** — access control, audit (see P5-04), integrity, transmission (TLS).
4. **Privacy** — access requests, accounting of disclosures, breach process (link PIPEDA/PHIPA if needed).
